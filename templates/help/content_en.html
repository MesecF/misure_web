User guide

Login and basics

  • To log in, select the company, enter your username and password and click Log in.
  • Each company sees only its own data.
  • There are two roles:
    • User enters and views measurements.
    • Administrator also maintains categories, elements and articles, and corrects and deletes measurements (menu Administration).
  • After 5 failed login attempts within 15 minutes the username is locked for 15 minutes, even with the right password. Wait and try again.
  • Change the language in the language menu in the top right corner (English / Hrvatski / Italiano), also before logging in. The choice is remembered in the browser.
  • When you are done, click Log out, especially on a shared computer.
  • The ? next to a page title opens the guide for that page in a new tab.

Entering measurements

Menu New measurement. The screen is made for a barcode scanner and a measuring device that send Tab after each reading. Everything also works with the keyboard alone.

  1. Enter your employee number. It stays for the next measurements until you change it.
  2. Scan the article barcode into the Barcode field, or type it and press Tab or Enter. The article data (code, color, size, category) appear, with a field for each element of its category.
  3. Enter the values. Tab or Enter moves to the next element.
    • A field can stay empty, but at least one value is required.
    • A value is a number of 0 or more with at most one decimal. The decimal sign can be a comma or a dot, e.g. 12,5 or 12.5.
  4. After the last element the window Save measurement? shows what was entered:
    • Enter (or the Save button) saves the measurement;
    • Esc (or Back) returns to the fields for a correction.
  5. After saving, a green message shows the time of saving and the fields are empty for the next measurement of the same article. Below them you see Today's measurements of this article.

Keys and buttons

F2 / New articleclears the barcode; scan the next article
F3 / Change employeeclears the employee number; enter the new one
Show element namesshows element names instead of codes next to the fields; remembered in the browser

Messages

  • No article with barcode … — the article is not in the list of articles. Tell an administrator.
  • Article … is inactive / Category … is inactive — this article is not measured at the moment.
  • Red message "the measurement was NOT saved" — the connection to the server was lost or the server reported an error. The entered values are still there. Check the connection (network, Wi-Fi) and save again: Enter on the last field, then Enter. Do not scan the next article until the measurement is saved (green message).
  • If the login page opens instead of the entry screen, the session has ended. Log in again; a measurement that was not saved has to be entered again.

Viewing measurements

Menu Measurements. It opens with today's measurements of all categories, 50 per page, newest first.

  • Filters: period (From – To), Category (or All categories), article code or barcode (part of it is enough), color, size and employee number. Click Filter; Reset restores the defaults.
  • Pick a date in the calendar or type it as dd/mm/yyyy. If From is after To, the dates are swapped automatically.
  • Element columns: for one category all its elements are shown, in the category's order. For all categories only elements with a value in the shown measurements are shown.
  • Show element names switches the column headers between codes and names. The export follows it.
  • Measurements show the code, color, size and category as they were when measured. Later changes of an article do not change earlier measurements.
  • The label corrected means an administrator corrected the measurement afterwards.
  • Details opens a single measurement: who entered it and when, and who corrected it and when.

Export to Excel and CSV

  • Export to Excel and Export to CSV export all records matching the filters, not only the page shown. While the file is prepared, the button shows Preparing file….
  • A measurement export can cover at most 366 days. For a longer period make several exports.
  • Excel (.xlsx) is recommended for opening in Excel: numbers, dates and barcodes are written correctly.
  • CSV is meant for other programs: columns are separated by ;, the decimal sign is a comma. Opened in Excel, barcodes show as 8,05952E+12. That is how Excel behaves; use the Excel export.

Correcting and deleting measurements administrator

  • In the measurement list click Edit. The employee number and the values can be corrected, not the article or the time of measuring. Click Save correction. Who corrected the measurement last and when is recorded; earlier values are not kept.
  • Delete measurement removes it from the list and the export. It is not deleted for good: switch on Show deleted, open it and click Restore measurement.
  • Users with the role User do not see deleted measurements.

Categories administrator

A category decides which elements are measured on its articles. Menu Administration → Categories.

  • New category: code and name. The code is unique regardless of upper or lower case.
  • Elements next to a category opens the elements measured in it:
    • add an element with its order, which sets the order of the fields when measuring. The next number is suggested (steps of 10, so an element can be inserted in between later);
    • the order can be changed and saved;
    • Remove takes the element out of the category. Saved measurements do not change.
  • Categories, elements and articles are not deleted but deactivated (Deactivate / Activate). Inactive records are not offered when measuring, and the measurement history stays complete.
  • Once a category has measurements, its code cannot be changed (finding measurements depends on it). The name can be changed.

Elements administrator

An element is a dimension that is measured, e.g. a length or a width. One element can be in several categories. Menu Administration → Elements.

  • New element: code (saved in upper case), name and unit (e.g. cm).
  • Once an element has measured values, its code and unit cannot be changed.
    • The name can be corrected, but the new name is also shown for earlier measurements in the list and the export.
    • If the element is to measure something else, create a new element and deactivate the old one.
  • Import CSV: columns code;name;unit, the first row is a header. Only new elements are imported; a code that already exists (also as an inactive element) is rejected. Example: B05;Lunghezza totale;cm. Then add the elements to categories.
  • The export follows the status filter and includes the categories of each element.

Articles administrator

Menu Administration → Articles. Search by code or barcode, filter by category and status.

  • An article has a code (up to 15 characters), color (up to 10), size (up to 10), category and barcode. Code, color and size are saved in upper case.
  • The barcode must be a valid EAN-13 (13 digits with a correct check digit).
  • Within a company neither the barcode nor the combination of code, color and size may repeat.
  • Import CSV: columns code;color;size;category code;barcode, the first row is a header. Example: UMC250C;8984;50;MAGLIA;8059522105740.
    • A new barcode adds an article. An existing barcode updates the article (an inactive one stays inactive).
    • The category must exist and be active.
    • Rows with errors are skipped and listed with the line number and reason; the valid rows are imported. The file can have up to 5 MB.
  • Changing an article does not change saved measurements.

CSV files and Excel administrator

  • In Excel: File → Save As and choose the type CSV UTF-8 or CSV. With Croatian or Italian Windows settings Excel separates the columns with ;, as needed.
  • Format the barcode column as text before typing or pasting barcodes (right click → Format Cells → Text). Otherwise Excel turns the barcode into a number (8,05952E+12) and loses digits, and the import rejects the row.
  • If the import reports Expected 5 columns, found 1, the file is not separated with ;, usually because it was saved with commas.
  • If it reports that the file cannot be read as CSV, an Excel workbook (.xlsx) or another format was chosen. Save it as CSV.

Common problems

Nothing happens after scanning
The cursor must be in the Barcode field. The scanner should send Tab or Enter after the barcode; otherwise press Tab after scanning. The same barcode is not loaded twice in a row: to load it again press F2 and scan again.
I cannot save, it says "Enter at least one value."
All element fields are empty. Enter at least one value.
A measurement is missing from the list
Check the period (by default only today) and the other filters, or click Reset.
I cannot log in
Check that the right company is selected. After 5 wrong passwords the login is locked for 15 minutes. For a new password contact your administrator.
{% if is_admin %}
I cannot change the code of an element or a category
The element or category already has measurements. See Elements and Categories.
I cannot delete an article, element or category
Deleting is not possible, on purpose, so that the measurement history stays complete. Use Deactivate.
